## 五、WP-R2 草案重写要点（替代原版）

原版（基于 047 六条修正）：改 CONTINUE_PROMPT 加推导链/负面知识/预算配速——**被 v2 架构取代**

重写版核心：
1. **三模板体系**：prompt_round1（纯解题者）/ prompt_observer（观察者）/ prompt_solver（专职解题者）——从主 repo `v2/prompt_*.md` 适配到本 repo 格式
2. **递归消化链目录**：`round{N}/` 下放工作笔记/分析笔记/thinking——替代平铺的 round{N}_HANDOVER.md
3. **budget_starved 终态**：指纹 = outputTokens==整数上限值（不豁免 message/tool）
4. **静默阈值 300 秒**
5. **oc_traj.py 工具接入**：解题 AI 可自助 scan/tail/search/read 前轮 thinking 档案
6. **主控角色收缩**：launcher 不代推数学、不写 HANDOVER、只做编排+断言+监督清单
7. **隔离区机制**：每轮启动前重建 `/tmp/<task>/` 隔离区复制历史目录（防项目 AGENTS.md 污染推理）
