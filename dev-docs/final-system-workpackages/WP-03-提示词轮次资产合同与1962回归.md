### 3.1 模板要求

### round1

题目、防作弊、过程工作笔记、截断可接续、增量形式化、临时验证资产归档、候选成功语义。

### observer

只分析不解题；亲自使用reader做scan→tail→search/inspect；五节+形式化状态+验证欠账；
禁止通读；分析紧邻前轮；
对更早档案只按需修正；不得读取最终答案 fixture。

### solver

只读最新分析笔记为主；推进单一缺口；过程工作笔记；增量形式化；proof/formal共同交付；
形式化不足可诚实停留为候选，不伪称最终正确。

## 五、1962离线回归

制作不含最终答案泄漏的 fixture/测试说明：

1. v1 HANDOVER 对照：检查新 observer 不只复述裸结论。
2. R2 现场：检查禁止通读和预算纪律。
3. R3 期望行为：尾部收殓、EEO组装、暴力搜索欠账、OOO缺口。
4. R4 现场→R5观察：复核新定理、执行欠账、修正笔误。

回归断言结构/行为/资产，不要求文本逐字一致，也不在线调用模型作为普通单测。真实模型
回归作为可选受控实验，需独立记录成本和模型配置。
