**问题**：SOP_06 要求写 MONITOR_REPORT.md，但 `check_06_report_worklog_selfcheck` 不检查该文件是否存在或是否被填写。
**处理方式**：在 `checks.py` 的 `check_06_report_worklog_selfcheck` 中加：
```python
report_path = repo_root / "MONITOR_REPORT.md"

    size = report_path.stat().st_size
    if size < 100:
        print(f"  ⚠️ MONITOR_REPORT.md 过小 ({size}B)，可能未填写")
    else:
```
