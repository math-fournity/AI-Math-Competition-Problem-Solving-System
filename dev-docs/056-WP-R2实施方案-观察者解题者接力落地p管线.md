## 三、设计决策（5 条，均已定）

1. **新增 v3 不动 v2**——`--method` 加第三选择，默认仍 v2。回退能力和 A/B 对比都保留，符合渐进式落地原则（049 矩阵#8）。
2. **观察者轮复用 Pipe A 骨架**——-p 路径没有 thoughts.jsonl/oc_traj 工具，观察者的输入档案就是 conversation.json + 面包屑地图（现成机制）；v2 观察者模板的"预算纪律"翻译成"按地图分段读取"。
3. **解题者轮自己读笔记文件，不内嵌**——prompt 只给路径和任务书。尊重 v2 哲学："笔记是接手者唯一输入"。devin cli 有文件读写能力（本来就要写 proof.md）。
4. **budget_starved 语义挂接到现有判定**——is_truncated=True 的轮在 rounds_log 的 reason 标 `budget_starved`；max_rounds 耗尽仍记 TRUNCATED_AT_MAX。检测函数零改动。
5. **round1 无交接直接解题**——用增强版初始 prompt（题目 + 形式化验证强制要求 + 防作弊条款 + 工作笔记纪律）。
