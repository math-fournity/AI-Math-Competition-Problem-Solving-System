## 二、五维评估

### 2.1 数学解题能力——按系统口径重判

- 单轮口径下 ox-alpha 在难题层全灭（思考打满预算）——但这正是系统的输入条件
- **续传收敛性 ✅ 实证**：95,884 字符截断思考经 CONTINUE_PROMPT_TEMPLATE 原文接力，
  round 2 以 inputTokens=57,710 真实消化前轮推理，205s 产出完整证明与 boxed 结论
  （对"注入张量积单射性"研究级难题给出 No+反例路线）
- 低强度直答层：4/5 出 boxed；其中 47/41 两题是 **glm-5-2 卡死未解出的题**
  （truncation 循环后停在 prepared）——ox-alpha 32s/94s 给出自洽解答
  （结论合理性初核通过，最终正确性留 Master Agent/领域复核——诚实声明）
- **对照 glm-5-2 历史**：同批题 glm 也大量依赖续传（039：153 道卡题）；
  两模型单轮能力同量级，差异在风格（glm 思考更紧凑，ox-alpha 思考更深更长）

### 2.2 reasoning 质量 —— ✅ 通过

抽样阅读 + 循环检测双验：真实数学内容（题目解析/v2 赋值分析/边界验证）、
349 个滑动窗口 100% 唯一（零退化循环）、被切断处是半句公式（证明是预算截断非幻觉发散）。

### 2.3 1M context 利用 —— ✅ 实证通过（亮点）

97,027 字符接力 prompt 直接接受并**真实消化**（inputTokens=57,710 证明前轮推理
进入了工作记忆），round 2 明确"在之前基础上继续"而非重推。这是 glm-5-2（200K）
紧张场景下 ox-alpha（1M）的差异化优势。

### 2.4 提示词兼容 —— ⚠️ 一项不符需适配

- CONTINUE 模板原文完全遵守（继续式推进、boxed、PROOF COMPLETE 标记）✅
- INITIAL 模板行为符合（解题/LaTeX/boxed）✅
- **❌ "把证明写到 proof.md 文件"未被执行**——全部 10 题均 message 输出、零 proof.md。
  处置：V4 适配器把组装 message 落盘为 proof.md（或模板加一句强调）；不改原文模板的
  兼容性测试结论如实记录为"文件写入指令遵从度低"

### 2.5 tool calling 行为 —— ✅ 干净

全部运行零 tool_call——无搜索题本身等作弊风险模式；防作弊约束理解无冲突
（副作用：也没用 Python 自我验证——纯思考风格）。

## 三、三分支结论

**有条件可作默认**（介于"可作默认"与"有条件默认"，倾向前者）：

成立依据：
1. 截断检测→续传→收敛的全链路在 OpenCode ACP 后端上实证走通
2. 低强度直答覆盖简单层（且能做出 glm 卡死的题——待复核）
3. 思考质量高、无幻觉循环、工具行为干净、提示词兼容（除 proof.md 一项可适配）
4. 免费+无限量+1M context 的运营优势不变

条件（交用户确认的决策点）：
1. **effort 策略**：max+续传（深思考，适合难题）vs low 直答（快，适合易题）
   ——建议作为 DB batch 可配参数（架构已支持），默认策略请用户定
2. **proof.md 适配**：V4 组装器落盘 message 为 proof.md（工程活，无悬念）
3. 正确率终审：47/41 两题及低强度答案的正确性需领域复核（本轮执行者即模型自身，
   按适度依赖原则不自评终审）
