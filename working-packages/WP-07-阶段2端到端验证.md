## 任务清单

### 1. 手动启动一轮Monitor Exec Devin

- [ ] 确认系统在运行（launcher+monitor）
- [ ] 等Monitor Pipe自动启动Monitor Exec Devin，或手动调`launch_monitor_exec`
- [ ] 观察Monitor Exec Devin的tmux session启动
- [ ] 确认prompt被正确传递（work_dir/monitor_exec_prompt.txt）

### 2. 验证完整流程

- [ ] Monitor Exec Devin运行检查脚本获取alert
- [ ] Monitor Exec Devin按alert类型分类处理
- [ ] Monitor Exec Devin修复代码bug（如有）
- [ ] Monitor Exec Devin写MONITOR_EXEC_REPORT.md
- [ ] Monitor Exec Devin写DONE.md退出
- [ ] Monitor Pipe检测到DONE.md，写monitor_exec_completed alert

### 3. 验证export完整保留

- [ ] 确认`/Volumes/data/p27-monitor-exec/{exec_seq}/conversation.json`存在
- [ ] 确认`/Volumes/data/p27-monitor-exec/{exec_seq}/DONE.md`存在
- [ ] 确认`/Volumes/data/p27-monitor-exec/{exec_seq}/MONITOR_EXEC_REPORT.md`存在
- [ ] 确认`/Volumes/data/p27-monitor-exec/{exec_seq}/WORKLOG.md`存在
- [ ] 确认`/Volumes/data/p27-monitor-exec/{exec_seq}/tmux/tmux.log`存在

### 4. 验证prompt约束

- [ ] 确认Monitor Exec Devin没有修改AGENTS.md
- [ ] 确认Monitor Exec Devin没有修改specs/下的文件
- [ ] 确认Monitor Exec Devin只commit了代码修复（没有push）

### 5. 验证防重复启动

- [ ] 在Monitor Exec Devin运行中，确认`should_launch_monitor_exec`返回False
- [ ] 确认不会启动第二个Monitor Exec Devin

### 6. 验证C类AI判断

- [ ] 确认Monitor Exec Devin读取了`needs_ai_review`标记的proof.md
- [ ] 确认Monitor Exec Devin按C1-C5标准做了真正的判断（不是只写标记）
- [ ] 确认判断结果被写入MONITOR_EXEC_REPORT.md

### 7. 验证自愈能力

- [ ] 构造一个代码bug（如故意改错一个路径常量）
- [ ] 等Monitor Exec Devin发现并修复
- [ ] 确认修复后commit
- [ ] 确认下一轮检查不再报告这个bug

### 8. 验证WORKLOG.md跨轮传递

- [ ] 第一轮Monitor Exec Devin写WORKLOG.md
- [ ] 第二轮启动时，确认WORKLOG.md从上一轮复制到本轮work_dir
- [ ] 确认第二轮的WORKLOG.md包含上一轮的内容+本轮续写
