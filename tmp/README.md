# tmp/ — 实验现场与证据暂存目录

> 本目录存放 WP 工作包实验与模拟系统的运行现场。已提交报告按路径引用本目录文件
> 作为证据（042/043/047、dev-docs/workpackages/WP-U1/U2/U6、dev-docs/017）。

## 入 Git 与本地保留的分界（2026-09-27 整理）

| 类别 | 处理 | 说明 |
|---|---|---|
| 各 WP 实验证据（jsonl 捕获/export/prompt/result.json/manifest） | **入 Git** | 报告按名引用；secret 扫描无真实凭据；单个最大 4MB |
| `tmp/wp_u6/*/*.jsonl`（每题完整会话捕获） | **仅本地保留** | 约 37MB 大体积原始捕获（`.gitignore` 排除）；同目录 `result.json` 判定汇总仍跟踪 |
| `*.log` / `tmp/**/*.tail` | **仅本地保留** | 全局 `*.log` 规则；`.tail` 为部分下载残片 |
| `tmp/sim/`（solver 工作目录 + traj 导出） | **入 Git** | 017 全流程模拟系统实测现场（proof/HANDOVER/prompt/conversation.json） |

## 铁律

- **资产保留铁律适用**：本目录下任何文件（含未入 Git 的大捕获与 log）禁止删除、
  覆盖、清理——失败轮的会话捕获是分析能力边界的核心数据。
- 引用这些路径的已提交报告（042/043/047 等）以本目录为证据真值源；移动或重命名
  会破坏引用链，须先更新报告再移动。
- 新实验产物默认落盘本目录并在工作包文档中引用；是否入 Git 按上表分界执行。
