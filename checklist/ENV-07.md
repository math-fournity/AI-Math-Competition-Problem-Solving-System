# ENV-07: 启动 devin cli 必须指定 glm-5.2-high

> **门类**: ENV · 环境与基础设施
> **状态**: [ ]
> **负责的WP**: —
> **来源**: 用户要求（2026-08-19）
> **所属章节**: §ENV · 环境与基础设施

## 需求描述

启动 devin cli 的时候，必须指明使用的是 `glm-5.2-high`，不能不指定这套模型和推理强度，就直接启动 devin cli。

## 验证方法

检查所有启动 devin cli 的命令/脚本/prompt 模板，确认都包含 `--model glm-5.2-high`（或等价的模型指定方式）。不指定模型和推理强度就启动 = 违规。

## 详细信息

- **约束级别**: 硬约束——所有 devin cli 启动必须遵守
- **适用范围**: 系统中所有启动 devin cli 的地方（脚本、launcher、prompt 模板、手动启动）
- **禁止行为**: 不指定模型直接 `devin -p '...'` 启动
- **正确行为**: `devin -p '...' --model glm-5.2-high` 或在脚本/模板中固化此参数
